# 15300 相对 12200 的变化

这里比较的是两个检查点实际保存的配置、参数形状和源码。12200 是参考基线，15300 是当前固定版本；真实分支父节点为 update 14255。先在原架构上从 12200 继续训练到 14255，再从 14255 加入真实提示泛化配方训练到 15300。因此性能差异同时包含额外训练和配方变化，不能全部归因于某个模块。

## 保持一致的部分

- 同一官方 Qwen3.5-0.8B，revision `2fc06364715b967f1860aea9cf38778875588b17`，冻结基座并训练 rank-8 LoRA。
- 六层跨帧 KDA、APOS → OPOS → 当前动作、六动作空间、四步动作计划和 arrival 辅助头。
- 当前 RGB + 目标文本 + 一个可选 HINT token + episode cache；均不输入历史整帧、深度、语义图、地图或真值位姿。
- APOS / OPOS 使用 48×27 网格，分层解码；规划融合与 arrival STOP 融合权重均为 0，执行当前一步后重新观测。
- rollout=100、反向 fragment=20，专家 / greedy DAgger / 随机 PPO 三路；PPO=0.25、未来动作监督为 `executed_prefix`。
- 相机、机器人、允许滑动、成功距离 0.25 m、奖励和起点课程在两个检查点配置中相同。

## 新增架构

只新增 `adaptation.*` 的 10 个 tensor，原有参数没有删除或改变形状。

| 模块 | 参数量 | 作用 |
|---|---:|---|
| 空间坐标适配 MLP | 132,480 | 将 HINT 网格中心的归一化二维坐标编码，加到原 HINT embedding |
| 视觉运动反馈 MLP | 133,760 | 编码上一实际动作、RGB 变化、视觉静止与交替转向计数，共 12 维 |
| HINT 质量辅助头 | 1,025 | 预测提示有效性，用于辅助监督和诊断 |
| 合计 | 267,265 | 可训练参数 8,981,568 → 9,248,833，增加约 2.98% |

输入仍只有一个 HINT token，融合方式为：`原 HINT embedding + 有点时的坐标残差 + 运动残差`。NULL 时坐标残差屏蔽，运动残差仍生效，因此无提示行为也会受到影响。坐标从离散网格 token 解码，不额外获得原像素的亚网格精度。

反馈使用相邻 RGB 的 8×8 缩略统计和实际动作；不使用仿真碰撞、真实位移或目标距离作为 actor 输入。缓存增加缩略统计与少量计数，KDA 张量仍约 12 MiB。新增 MLP 输出层和质量头曾零初始化，以便接入时保持父模型输出；15300 已训练，当前输出不为零。

质量头没有直接覆盖动作或作为 HINT 硬门控。已有 HINT token、四步规划、到达头并不是 15300 新增的能力。

## HINT 数据与监督

| 配方 | 12200 | 15300 |
|---|---|---|
| episode 提示分配 | 50% 模拟点，50% NULL | 50% 真实 YOLOE，25% 模拟点，25% NULL |
| 真实检测 | 未加入训练 | YOLOE-v8l-seg，单个候选点 |
| 连续干扰点 | 无 | 8% 概率，连续 6 帧，逐帧重新投影 |
| 质量辅助监督 | 无 | BCE 系数 0.1，已知正负样本平方根平衡 |

这些是 episode 分配比例；检测器漏检、目标不可见时仍输入 NULL，不代表 75% 的帧都有点。模拟点两版本都保留 20% 缺失、1 格支持域扰动和 1% 随机误报。

真实点原样进入策略和标注服务，携带 episode / frame 绑定；教师根据实际输入点决定路线，bootstrap 复用同帧检测包。质量监督对官方目标为正；同类但未纳入官方目标的歧义实例、未知标注均屏蔽，不强行当负例。语义资产只生成监督与评估标签，不进入 actor。

新增困难状态动作 IL 加权：持续停滞 / 交替转向 2 倍，可判定错误 HINT 1.5 倍；权重在完整分布式 rollout 上归一化。原有碰撞恢复 3 倍、STOP IL 权重 1、到达与停止辅助项继续保留。

## 学习率和 Grounding 混合

LoRA LR 从 `1e-5` 降到 `5e-6`；新增 adaptation LR 为 `1e-4`。其他组不变：KDA / point `5e-5`，action / critic `1.5e-4`，planning `3e-4`，HINT / arrival `1e-4`。当前保留旧 Adam 组状态，新增组在分支建立时初始化。

| Grounding 来源 | 12200 | 15300 |
|---|---:|---:|
| COCO instance | 38% | 25% |
| Referring | 48% | 30% |
| ScanNet instance | 11% | 30% |
| ImageNet localization | 2% | 10% |
| PixMo points | 1% | 5% |

原 manifest、图像 / 场景划分和哈希不变，提高了室内与长尾来源的采样权重。动作 IL、point、未来动作、grounding、PPO 和 value 的基本系数保持一致。

## 保存的证据

当前权重在 `checkpoints/fastvln_15300`，12200 在 `checkpoints/reference_12200`；各自保存配置、manifest 与原始源码快照。300 例原始指标、case 列表、配置、trace 和已录制视频统一在 `runs/comparison_300_15300`。15300 的 tensor-content 哈希与原检查点一致，当前默认路径的调整没有改写模型 tensor。
