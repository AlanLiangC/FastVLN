# 原生 point CoT

沿用 LightNav 原点位词表：APOS 有 1300 个允许 token，OPOS 有 1297 个允许 token。token 1–1296 对应 48×27 网格，0 表示无点；APOS 1297/1298/1299 分别表示左转、右转、停止。APOS 表示运动可行位置，OPOS 表示目标位置，不增加 segmentation 或到达分类头。

模型依次生成 APOS、OPOS 和动作。OPOS 条件于实际选择出的 APOS；动作读取这两个 token 后生成。训练重放使用 rollout 中的实际 token，不能以教师点位替换输入后仍用旧策略概率计算 PPO。

每四步调用一次冻结的原 LightNav，使用当前帧和最多八帧历史 RGB，得到点位软分布。APOS 分布直接蒸馏；OPOS 教师同样条件于学生采样的 APOS，使分布对应同一前缀。教师仅在训练期使用历史帧，不将历史图像传入学生策略。

点位保留采用允许词表内的 KL，并对稀疏调用频率补偿。冻结教师提供保留信号，不等同于真实标注；当前数据任务是 ObjectNav，原模型的点位能力仍需要实景闭环检验。原先由三维物体中心投影产生的弱点位监督不用于本版本。

评估视频显示鲜明 APOS 与 OPOS 标记及动作概率。额外 token 没有可画的网格坐标时显示状态文字，不能画成图像中的目标点；视频的点位是实际生成 token，尖峰概率是模型置信度，不是正确率。
